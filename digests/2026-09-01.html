🌟 极大维度推荐

  1. Real-Time Scene-Adaptive Tone Mapping for High-Dynamic Range Object Detection [2608.30400]
    亮点：用神经光度标定 + 尺度不变局部色调映射替代传统 ISP，端到端联合下游检测优化，把 HDR RAW 桥接到检测网络所需的 LDR sRGB；支持性能迁移微调，在 Jetson 上实时处理 4K 高位深 HDR，优于传统 TMO 与先进 AI-ISP。
    代表性维度：①突破性/③相关度：当天唯一命中的核心影像主线工作，直击端侧 ISP/HDR/色调映射与下游任务联合优化，与计算摄影链路高度相关。
  2. DreamX-Creator: Democratizing Native Audio-Video Generation at 2K Resolution [2608.31106]
    亮点：7B 原生音视频联合生成：首帧+文本条件下同时去噪音频与视频流，前半独立处理、后半以门控跨模态注意力耦合，直出 2K 分辨率，改善视觉动态与声学事件的互建模。
    代表性维度：②影响力/③相关度：紧凑参数下的高分辨率原生音视频联合生成，贴近视频拍摄/制作链路。
  3. Matrix-Game 3.5: Enhancing Real-Time Streaming Interactive World Models with Patch Memory [2608.29910]
    亮点：以 Patch Memory 支撑实时流式交互世界模型，长时程自回归生成中同时保持场景几何、动态一致性与相机控制，面向游戏/机器人/具身/XR 的持续可交互模拟。
    代表性维度：①突破性/③相关度：实时自回归视频生成与相机控制，与端侧实时视频处理诉求相通。
  4. Off-Manifold Refinement: Guiding Video Generators with a Frozen World Model [2608.29904]
    亮点：用冻结世界模型引导视频生成器、显式惩罚物理违例（漂浮/穿模/接触消失），相比候选筛选与梯度式世界模型引导更省推理与训练开销。
    代表性维度：①突破性：以低成本方式注入物理一致性约束，改进视频生成的动力学真实度。
  5. DocIntent: Answerability-Guided Agentic Restoration for Real-World Document Visual Question Answering [2608.29037]
    亮点：免训练、可答性引导的智能体式图像修复：针对模糊/阴影/畸变/摩尔纹选择性调用修复工具，比较式回滚校验每步，令修复服务下游文档 VQA 而非通用画质指标。
    代表性维度：③相关度/④覆盖面：把图像修复置于任务导向的智能体框架，是 low-level 修复与上层任务耦合的代表思路。
  6. NoisEasier: Test-Time Noise Optimization for Text-to-Video Generation [2608.30194]
    亮点：文本到视频的测试时缩放框架，用可微奖励引导优化初始噪声、无需改动生成模型，提升属性绑定/空间关系/物体交互等细粒度对齐并规避奖励攻击。
    代表性维度：①突破性/③相关度：推理期噪声优化的即插即用对齐方案，对视频生成质量提升有普适价值。
  7. FaceSnap: Real-Time Personalized Lightstage Facial Performance Capture [2608.31033]
    亮点：两阶段面部捕捉：先一次性多视图优化构建含几何与表情相关外观的个性化模型，再实现轻量实时捕捉，缓解 Lightstage 多相机、算力与存储瓶颈。
    代表性维度：③相关度/④覆盖面：面向生产级数字人的实时化影像捕捉，属计算摄影/多视图成像外延。
