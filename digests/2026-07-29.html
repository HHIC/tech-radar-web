  1. Wonder: Video World Model Done Better [2607.26037]
    亮点：通用视频世界模型，给定单图或条件视频即可构建可实时、相机可控地导航探索的可玩世界，把视频生成推向交互式世界模型。
    代表性维度：①突破性——将视频生成从被动生成推进到实时可控的世界建模范式。
  2. Parallel Decoding Distillation for Fast Image and Video Generation [2607.26004]
    亮点：针对扩散/流模型迭代采样慢的痛点，提出并行解码蒸馏，摆脱对变分分数蒸馏的重度依赖，加速图像与视频生成。
    代表性维度：②影响力——推理加速是生成模型落地的关键瓶颈，方法通用性强。
  3. PerceptionBench: Evaluating Atomic Visual Perception in Multimodal Large Language Models [2607.24957]
    亮点：专门隔离并评测 MLLM 的原子级视觉感知能力，弥补现有整体式基准无法把感知从推理中剥离的缺陷。
    代表性维度：③相关度——多模态评测精细化，直击 MLLM 感知短板。
  4. SepPrune: A Separator-based Pruning Framework for Efficient Multimodal Large Language Models [2607.25818]
    亮点：面向 Qwen2.5-VL/InternVL3 等在高分辨率输入下产生海量视觉 token 的问题，提出基于分隔符的视觉 token 剪枝框架降算力。
    代表性维度：②影响力——高分辨率 MLLM 部署的实用效率方案。
  5. Desktop-Delta Bench: Do Computer-Use Models Understand Desktop GUI Transitions? [2607.26041]
    亮点：面向计算机使用智能体（CUA）的新基准，专门考察模型能否理解桌面 GUI 的状态转移，而非仅测端到端成功率或单帧定位。
    代表性维度：①突破性——为 agent 领域补上 GUI 动态转移理解这一评测空白。
  6. Instruction-based Image Editing: A Survey on Data, Models, Evaluation, and Applications [2607.25642]
    亮点：系统综述指令式图像编辑（IIE）的数据、模型、评测与应用，梳理 LLM/VLM 驱动下的进展全景。
    代表性维度：④覆盖面——指令编辑方向的权威梳理，便于快速建立全局认知。
  7. Explicit Layer Modeling for Video Object Insertion and Layer Decomposition [2607.25802]
    亮点：为视频编辑引入显式分层视频表示，支持真实合成、对象复用与一致性操控，弥补现有系统缺乏图层表示的短板。
    代表性维度：③相关度——直接推进视频编辑的可控合成能力。
  8. MODUS: Decoder-Only Any-to-Any Modeling of Diverse Modalities [2607.25948]
    亮点：纯解码器架构的 any-to-any 模型，在单一网络内由任意模态组合预测任意模态，覆盖视觉-语言乃至科学领域。
    代表性维度：①突破性——统一多模态生成的架构探索。
  9. VIPER: Visual In-Context Physics Reasoning for Physically Plausible Video Generation [2607.23472]
    亮点：通过视觉上下文物理推理，让视频生成模型在标准文本/图像条件外获得物理行为可控性，缓解物理不合理问题。
    代表性维度：①突破性——把物理常识注入视频生成的可控性研究。
  10. Shieldstral [2607.25857]
    亮点：3B 参数的策略自适应多模态安全分类器，文本安全上匹配/超越近 7 倍体量的模型，并在多模态安全上刷新 SOTA。
    代表性维度：②影响力——小体量多模态安全护栏，部署友好。
  11. ReDesign: Recovering Editable Design Structures from Images via Agentic Decomposition [2607.25565]
    亮点：以 agentic 分解从栅格图像恢复可编辑设计文件（含排版等多模态属性），破解设计工作流中费时的反向工程瓶颈。
    代表性维度：③相关度——agent 与图像理解结合的实用落地场景。
