🌟 极大维度推荐

  1. Twins: Learn to Predict Unified Representations with Focal Loss [2607.22531]
    亮点：把 ViT 语义特征与 VAE 低层 latent 在同一 token 网格上按通道拼接，构成统一的连续 token 空间，同时支持多模态理解与图像生成且不增加序列长度/注意力开销。
    代表性维度：①突破性 — 直击统一多模态模型"理解用语义、生成用像素"的表征割裂痛点，路线简洁可扩展。
  2. dRAE: Representation Autoencoder with Hyper-Spherical Codes [2607.22148]
    亮点：指出标准欧氏码本目标与表征空间各向异性几何不匹配是码本坍缩根因，提出超球面离散码把高维视觉表征量化后对接语言模型。
    代表性维度：①突破性 — 为视觉离散化/token 化提供新的几何视角，与 Twins 形成"连续 vs 离散"对照。
  3. TRaM-VSR: Importance-Aware Token Routing and Merging for One-Step Diffusion Video Super-Resolution [2607.22231]
    亮点：针对 DiT 视频超分的二次时空开销，用 token 重要性路由+合并做自适应分配，在一步扩散下缓解细节丢失与时序闪烁。
    代表性维度：③相关度 — 视频处理/低层 CV 与端侧效率高度相关，一步扩散是当前落地热点。
  4. IR275K: A Benchmark for Infrared Multi-Frame Super-Resolution Toward Efficient Remote Sensing [2607.22380]
    亮点：面向红外遥感构建大规模多帧超分基准，显式刻画热对比度、传感器噪声、弱纹理与帧间平台抖动，统一此前碎片化的私有数据集与评测协议。
    代表性维度：④覆盖面 — 多帧融合/超分主题的数据集类代表作，填补红外 MFSR 评测空白。
  5. Robot-Factored World Models via Robot Rendering [2607.22535]
    亮点：把动作条件视频世界模型解耦为"机器人本体实现动作"与"场景响应"两过程，避免直接学实现过程或泄漏交互结果，提升预测保真度。
    代表性维度：①突破性 — 世界模型/具身智能的建模范式创新，因子化思路有普适性。
  6. Deformable Triangle Splatting: Flexible Primitives for Real-Time Radiance Field Rendering [2607.22446]
    亮点：为每条三角形边引入 K 个可学习标量位移控制点，使凸边界基元能表达非凸/凹曲结构，减少辐射场渲染所需基元数量。
    代表性维度：①突破性 — 3D 渲染基元的表达力升级，实时辐射场方向有影响力。
  7. LayoutLite: Token-Level Implicit Layout Analysis for Efficient Document OCR [2607.22200]
    亮点：不依赖显式版面检测，用即插即用的隐式版面分析在 token 级压缩文档图像的冗余视觉 token，同时保留 OCR 关键细粒度信息。
    代表性维度：③相关度 — VLM 文档 OCR 的效率优化，端侧/多模态落地相关度高。
  8. InnoText: A Unified Model for Visual Text Generation and Editing [2607.22101]
    亮点：统一视觉文字生成与编辑，针对小字号与中文等非拉丁脚本的结构规整性与可读性做优化，避免单任务模型的冗余训练管线。
    代表性维度：③相关度 — 视频编辑/生成式图像处理方向，中文文字渲染实用价值突出。
  9. Spectral Prior for Reducing Exposure Bias in Diffusion Models [2607.22091]
    亮点：揭示扩散采样中训练/推理存在频率相关 SNR 误差且方向随模型与时间步变化，提出轻量的谱对齐（SPA）用预计算先验校准中间预测功率谱。
    代表性维度：①突破性 — 从频域重新解释扩散曝光偏差，方法轻量、通用性强。
  10. Rethinking Multi-Branch and Cross-Backbone Fusion for Vehicle Re-Identification in the Foundation-Model Era [2607.22068]
    亮点：实证表明基础模型时代单个 DINOv3-预训练 ConvNeXt 配合调优配方即可匹敌依赖元数据的复杂多分支基线（VeRi-Wild 88.19/77.47 mAP）。
    代表性维度：②影响力 — 对"多分支/CNN-Transformer 融合更优"的常识提出反思，方法论价值高。
  11. Time-Reversed Imaging: A Multimodal Benchmark and Framework for Reconstructing Past Human-Environment Interactions [2607.22352]
    亮点：提出"时间反演成像"新范式，从热成像/紫外/可见光的残留物理痕迹推断刚发生过的人-环境交互，并发布首个三模态数据集 TRACE-HEI。
