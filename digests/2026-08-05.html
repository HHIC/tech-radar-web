🌟 极大维度推荐

  1. UniWorld-Design: From Pixel Generation to Layer-Native Design [2608.03971]
    亮点：把图像生成从平面像素合成重定义为结构化图层组合：以语义 RGBA 图层为生成/理解/编辑的原子单位，赋予多模态生成模型设计师式的图层原生工作空间。
    代表性维度：①突破性——从像素范式转向图层原生设计，重塑生成式设计的表示与交互方式。
  2. JoyAI-Video-Edit: Real-Time Open-Ended Video Editing with Autoregressive Diffusion [2608.03974]
    亮点：16B 自回归扩散实时开放式视频编辑：分块 AR 适配 + 源锚定分布匹配蒸馏(SA-DMD) + 长时程 AR 蒸馏，无需未来帧或预设时长，两步生成即保真且长时序一致。
    代表性维度：①突破性——把开放式视频编辑推进到实时因果生成，兼顾源保真与长时程一致。
  3. ParVL: Parallel Scaling and Expandable Compute Allocation for Multimodal LLMs [2608.04010]
    亮点：并行视觉-语言扩展框架：复用现有 ViT/LLM 主干做并行计算扩展，打破 ViT 与 LLM 间僵化固定的算力分配，可按任务弹性调配，避免显存/延迟激增。
    代表性维度：①突破性——提出与参数/序列扩展正交的并行扩展维度，重构 MLLM 的算力分配。
  4. Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent [2608.03979]
    亮点：将多模态 agent 从静态图扩展到连续视频流：诊断出模态偏置与参数知识泄漏两大瓶颈，提出解耦感知-探索、分阶段的视频深度研究框架。
    代表性维度：③相关度——多模态 agent 与视频理解交叉，切中长时程视觉工具增强推理的核心难题。
  5. StreamDAM: Presence-Aware Memory for Real-Time Streaming Video Object Segmentation [2608.03912]
    亮点：揭示顶尖离线 VOS 跟踪器在 30fps 诚实流式协议下崩溃（记忆太慢、对目标是否在场无感知），从记忆管线入手重建面向流式的在场感知记忆。
    代表性维度：①突破性——把 VOS 评测拉回真实时钟约束，重新定义实时跟踪的记忆设计。
  6. SlimVLM: Sensitivity-aware Dynamic Structured Pruning with Adaptive Visual Token Selection [2608.03580]
    亮点：面向端侧的 VLM 结构化剪枝：先做自适应视觉 token 选择去除冗余，再敏感度感知地动态剪枝，避免冗余视觉 token 干扰重要性估计导致的精度崩塌。
    代表性维度：③相关度——直指 VLM 端侧/资源受限部署，与手机影像/端侧算力主题高度相关。
  7. OmniPack: Unified Token Compression for Efficient Omni-modal Large Language Models [2608.03812]
    亮点：全模态 LLM 的统一 token 压缩：兼顾 LLM 前压缩易丢全局证据、LLM 内压缩欠挖 query 条件音视频协同两种缺陷，在低 token 预算下保持性能。
    代表性维度：④覆盖面——覆盖音视频全模态高效推理，代表 MLLM 效率优化的前沿方向。
  8. Attention is Case-Sensitive [2608.03711]
    亮点：系统实证发现 LLM/VLM 注意力对字母大小写敏感：大写/交替大小写在小写语境中天然充当显著性线索，跨 13 个模型（9 LLM+4 VLM、不同分词）稳定成立。
    代表性维度：①突破性——揭示注意力机制一个此前未被刻画的普遍属性，具方法论启发。
  9. LiteMVS: Efficient Multi-View Stereo with Foundation Distillation and Expert Aggregation [2608.03851]
    亮点：高效多视图立体：基础模型蒸馏 + 专家聚合，融合几何对应（弱纹理/重复区易失效）与单目深度强先验，面向机器人/AR/具身实时 3D 感知与 4D 表征。
    代表性维度：③相关度——低层 3D 视觉与端侧实时几何重建，贴合影像/计算摄影底层能力。
  10. GeoMAR: Unleashing Geometrically Aligned Features for Masked Autoregressive Blind Face Restoration [2608.03923]
    亮点：盲人脸修复：用双输入提取组件级几何文本先验作显式空间锚点，与低质特征对齐融合，再以掩码自回归精化，缓解严重退化下条件模糊与预测脆弱。
    代表性维度：③相关度——图像修复/复原核心任务，与低层视觉、图片处理主题直接相关。
  11. CoT-Edit: Let CoT Guide Instruction Video Editing [2608.01113]
    亮点：plan-guide-edit 框架：CoT 增强的 MLLM 作规划器对视频与指令结构化推理，导出精确框序列，桥接语义意图与空间执行，缓解纯文本提示的目标歧义与物理不合理。
    代表性维度：④覆盖面——指令式视频编辑，代表生成式视频编辑与 MLLM 规划的结合方向。
