  2. LayerRecall: A State-Conditioned Memory Router for Long-Horizon Consistency in Video Generation [2608.28460]
    亮点：发现视频 DiT 各层对当前/近期/远端上下文偏好不同，用状态条件记忆路由让长视频在主体与场景重现时保持一致。
    代表性维度：①突破性/③相关度：长视频生成一致性，贴近视频拍摄/生成主线
  3. DensityKV: Density-Guided KV Cache Compression for Long Video Generation [2608.27922]
    亮点：针对自回归长视频生成历史 KV 无限增长与冗余，做密度引导的缓存压缩，在维持长程一致性的同时降存降算。
    代表性维度：③相关度：面向长视频生成的效率优化，利于端侧/流式部署
  4. Visual Token Coding for Video Multimodal Large Language Models [2608.28008]
    亮点：借鉴 HEVC 的 I/P 帧预测与残差冗余度量，对视频 MLLM 做结构化 token 压缩，并引入动态分辨率与动态 token 分配。
    代表性维度：③相关度：将经典视频编码思想迁移到视频大模型效率
  5. Manifold4D: Denoising on Point Cloud Rendered Manifolds for Video Re-shooting [2608.28174]
    亮点：视频“重拍”沿新相机轨迹重渲染动态场景，在点云渲染流形上去噪，缓解渲染条件与源视频在去噪步相互竞争的信任困境。
    代表性维度：③相关度：新视角视频重渲染，最贴近影像/视频处理主线
  6. Lossy Event Compression: From Event Stream Distortion to Task Performance [2608.28429]
    亮点：指出现有事件流失真度量无法预测任务级退化，提出以任务性能为准绳的事件相机有损压缩评估思路。
    代表性维度：③相关度：事件相机传感/带宽压缩，关联端侧影像采集
  7. Video Generative Models as Geometry Learner [2608.28549]
    亮点：把视频生成模型当作几何学习器统一深度/法线等估计，利用多几何目标的内在关联，减少各任务独立微调开销。
    代表性维度：④覆盖面/①突破性：视频生成向几何理解迁移的新范式
  8. CAITLYN: Can LLM Agents Autonomously Synthesize Defenses against Emerging Injection Attacks? [2608.27990]
    亮点：探索 LLM 智能体自主合成防御以应对新型提示注入攻击，试图打破现有防御在鲁棒性/效用/覆盖间的三难权衡。
    代表性维度：④覆盖面：Agent 安全方向代表作（泛领域）
